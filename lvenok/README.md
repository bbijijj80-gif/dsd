# lvenok

Маскот-виджет: лвёнок (львёнок) с советом по Linux, который висит
в углу терминала и обновляется по таймеру. Советы — заранее заданный
список в `tips.txt` (см. также `../linux_tips` — модуль ядра с той же идеей,
но через `/proc`).

## Вариант 1: обычный терминал, без зависимостей

```bash
./lvenok.sh start    # запустить в текущем терминале (нижняя строка)
./lvenok.sh status
./lvenok.sh stop      # обязательно останавливать перед закрытием терминала
```

Как это работает: скрипт резервирует последнюю строку экрана (`tput csr`)
и раз в `LVENOK_INTERVAL` секунд (по умолчанию 15) перерисовывает её
случайным советом из `tips.txt`, не трогая остальной вывод.

**Ограничения** (честно, чтобы не удивляться):
- при изменении размера окна терминала нужно `stop` → `start` заново;
- работает per-terminal (отдельный процесс и PID-файл на каждый tty);
- если забыть `stop` и просто закрыть окно, зарезервированная строка
  экрана может остаться "сломанной" в это конкретное tty (на новый
  терминал не влияет) — почини командой `tput csr 0 $(($(tput lines)-1))`.

## Вариант 2 (надёжнее): статус-бар tmux

Если пользуешься tmux — это правильный инструмент для "всегда видимого
угла экрана", без ограничений варианта 1 (tmux сам управляет своей
статус-строкой, ресайзы и полноэкранные программы ей не мешают).

Добавь в `~/.tmux.conf`:

```tmux
set -g status-right "#(/полный/путь/до/lvenok/tip.sh)"
set -g status-interval 15
```

и перезагрузи конфиг: `tmux source-file ~/.tmux.conf`.

## Автозапуск при открытии терминала

Чтобы лвёнок стартовал сам, добавь в `~/.bashrc` (для варианта 1):

```bash
[[ $- == *i* ]] && ~/dsd/lvenok/lvenok.sh start >/dev/null
```
