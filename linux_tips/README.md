# linux_tips

Loadable kernel module (LKM), который отдаёт текстовые советы по Linux из
заранее заданного (захардкоженного в модуле) набора строк — без какой-либо
динамической генерации.

## Что делает

- При загрузке модуля пишет один случайный совет в лог ядра (`dmesg`).
- Создаёт файл `/proc/linux_tips`: каждое чтение (`cat`) возвращает один
  случайный совет из встроенного списка.
- При выгрузке модуля убирает `/proc/linux_tips` и пишет сообщение в лог.

Список советов задан массивом `tips[]` в начале `linux_tips.c` — чтобы
добавить свои, достаточно дописать туда строки.

## Требования

- Заголовки ядра, соответствующие версии запущенного ядра:
  `/lib/modules/$(uname -r)/build` (пакет обычно называется
  `linux-headers-$(uname -r)` в Debian/Ubuntu или `kernel-devel` в Fedora/RHEL).
- Права root для `insmod`/`rmmod`.

> В песочнице, где писался этот модуль, заголовков ядра нет (контейнерное
> окружение без сборки модулей), поэтому сборка здесь не проверялась.
> Собирайте и тестируйте на обычной Linux-машине или в VM/QEMU с
> установленными заголовками своего ядра.

## Сборка и запуск

```bash
make                 # собрать linux_tips.ko
sudo insmod linux_tips.ko
dmesg | tail -5       # увидеть совет дня в логе
cat /proc/linux_tips  # получить совет по запросу
sudo rmmod linux_tips
make clean
```

Либо через шорткаты в Makefile: `make load` / `make unload`.
